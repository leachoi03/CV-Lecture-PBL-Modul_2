## 디버깅 기록

AI가 만든 코드에서 발견한 오류, 원인, 해결 방법을 기록한다.

- (예) 날짜 / 증상 / 원인 / 해결 / AI 답변이 맞았는지
- 2026-11-19 / AI Hub 시퀀스 결과 영상에서 실제 차량·버스에 박스가 없고 노면 표시에만 car 박스 / 프레임이 띄엄띄엄 섞여 있어 ByteTrack이 움직이는 객체를 확정하지 못하고 정지한 오검출만 추적 / 연속성 검사 경고 추가, 이 데이터는 검출 평가용으로만 사용 / 결과 프레임을 직접 보고 확인함
- 2026-11-19 / 검출 평가 정밀도가 0.42로 비정상적으로 낮음 / 정답 라벨이 화면 일부 차량에만 있어 라벨 없는 실제 차량이 FP로 집계됨 / 카메라별 라벨링 영역 밖 검출 제외(정밀도 0.42→0.56). 영역 안 누락도 있어 정밀도는 하한으로만 해석 / 시각화 이미지를 직접 보고 확인함
